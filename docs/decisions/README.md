# Architecture Decision Records

A short record of significant technical decisions for this repository: the situation, what was decided, and the trade-offs. New entries are numbered sequentially and never edited after being merged - a changed decision gets a new entry that supersedes the old one.

Each record follows the same structure: Status, Context, Decision, Consequences.

## References to other repositories

Numbers in this index refer to decisions in this repository only. This baseline serves other repositories that rely on it, and some decisions here follow from decisions recorded there. Those are referenced by full link, never by number alone, for example: [aws-detection-as-code ADR 0011](https://github.com/corey-dwyer/aws-detection-as-code/blob/main/docs/decisions/0011-shared-security-baseline-in-dedicated-account-and-repository.md).
